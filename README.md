# Simple Instruction Architecture (SIA)

## A CPU simulator implementing the core functions of a CPU with an assembler to run assembly instructions.

This project was created for ICSI 404 - Computer Architecture and Organization

This is a simplified CPU simulator written in java. It is capable of running string arrays of instructions written according to the documentation. The instruction set documentation is included with the project and describes the available instructions, registers, and machine-code format. Some of the features include:

* An L1 and L2 cache for faster execution.
* 32 general-purpose registers.
* An Arithmetic Logic Unit (ALU) for performing arithmetic and logical operations.
* Instruction decoding and execution.
* A program counter for tracking instruction execution.
* A call stack for managing function calls.
* An assembler for converting assembly instructions into machine code.
* Branching and control-flow instructions.
* Memory-mapped storage for simulated memory.
